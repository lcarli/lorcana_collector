Sincronização entre dispositivos

Sua coleção é salva num GitHub Gist privado. Use o mesmo Gist ID + Token em todos os seus dispositivos para sincronizar.

  1. Crie um gist privado com um arquivo chamado lorcana-collection.json e conteúdo {}. Copie o Gist ID da URL (parte depois do seu username).
  2. Crie um Personal Access Token (classic) marcando apenas o escopo gist.
    ⚠ Use o "classic" — a API de Gists do GitHub não funciona com tokens fine-grained.
  3. Cole os dois abaixo. O token fica salvo só neste dispositivo.
